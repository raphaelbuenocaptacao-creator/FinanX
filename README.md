# FinanX

PWA de controle financeiro pessoal.

## Recursos atuais
- Dívidas por pessoa/empresa, valor e vencimento
- Parcelamento e valor por parcela
- Atrasos destacados automaticamente
- Marcar dívida como paga
- Gastos mensais por categoria
- Receitas
- Investimentos
- Totais, saldo projetado e indicador de saúde financeira
- Persistência local no dispositivo
- Instalação como PWA e funcionamento offline

## Próxima evolução planejada
- Login individual
- Sincronização em nuvem
- Banco de dados por usuário
- Calendário de vencimentos
- Metas financeiras
- Reserva de emergência
- Evolução patrimonial
- Exportação e backup
- Alertas de vencimento
- Dashboard histórico mensal
